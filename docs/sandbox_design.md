# Execution Sandbox Architecture

## Purpose
To execute untrusted Python code generated by the Developer Agent or test suites created by the Tester Agent within a strictly isolated, resource-constrained container environment.

## Security Controls
- **Network Isolation:** Disables external network access during execution.
- **Resource Constraints:** Imposes strict memory (e.g., 256MB) and CPU limits.
- **Timeout Restrictions:** Prevents infinite loops or resource exhaustion (e.g., 10-second threshold).
- **Filesystem Isolation:** Uses read-only or ephemeral temporary volumes without access to host mounts.
